# 2026-10-13

I moved the old site's content into the new one. Each instrument and machine
now has its own page with a photo, a quick start, common mistakes and its
manual: the Agilent DSO6012A scope, E3647A power supply, 33220A function
generator, Fluke 45 meter, two Prusa MK4 printers, the LPKF ProtoMat S104 PCB
mill and the ProtoFlow E reflow oven, 14 pages in all. I rewrote the rules that
were pictures as real text, and added safety, FAQ and three short guides.

Then I added tools for students:

- Calculators for resistor color codes, voltage dividers, LED resistors, RC
  cutoff and standard resistor values.
- A PCB file checker. It reads Gerber and Excellon files in the browser and
  checks them against the lab's milling rules: TOP/BOT/DRL/BOA file names,
  Excellon drill format, and board size under 8 x 6.5 in.
- Forms that write problem reports and poster print requests as emails.
- Search across the whole site.

Next: test everything.
