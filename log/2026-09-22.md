# 2026-09-22

I identified the boards: ten Makerfabs MaUWB_DW3000, each with an ESP32-WROVER-B,
an STM32F103, and a DW3000 UWB radio. The ESP32 controls the STM32 over serial
with AT commands.

Most example code online, including the vendor's own ESP32 sketch, uses pins for
the newer ESP32-S3 version. I found the correct pins for this board.

I wrote an Arduino self-test that checks the chip, flash, PSRAM, I2C, OLED, the
STM32 link, and WiFi, plus a Python script that reads the results. I tested it
with fake reports first.

I flashed board 1 and it passed: 16MB flash, 4MB PSRAM, OLED at 0x3C, STM32
responding.

I found and fixed two wrong checks in my test, PSRAM size and MAC address.

Next: the other nine boards, then the ranging test, which needs two at once.
