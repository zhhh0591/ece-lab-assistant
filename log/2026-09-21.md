# 2026-09-21

I got the task: test a batch of circuit boards and find out which ones still
work. How to do it was up to me.

I wrote a five-step test order for every board:

1. Visual check, power off
2. Each power rail to ground with a meter
3. Power up with the current limit set low
4. Measure the rail voltages
5. Check that it works

I check for shorts before powering up because a shorted rail can kill the
regulator.

I set up a spreadsheet for results, one row per board.

I looked into building a test fixture and decided against it. Most of these
boards are different, so it would need re-aligning for each one.

Next: find out what's in the batch.
